Create a mobile‑first website UI for “Susie’s Jewelry Repair” (Pasadena, TX). Visual style: captivating, luxury, modern, trustworthy. Use brand colors inspired by the logo/business card: deep burgundy + gold accents, high‑contrast neutrals. Typography should feel elegant and premium (serif headline + clean sans for body). Focus on mobile layout first, then adapt to desktop.

Pages: Home, Services, About, FAQ, Contact, Blog.  
Primary CTAs: “Get Fast Quote” and “Book a Repair.”  
Secondary: “Call Now” and “Get Directions.”

Home page sections (in order):
1) Hero: full‑bleed jewelry image, bold headline, subhead, two CTAs.  
2) Trust strip: years in business, same‑day assessment, insured, local.  
3) Services grid (see list below).  
4) “How it works” steps: Drop‑off → Assessment → Repair → Pickup.  
5) Testimonials slider.  
6) FAQ teaser + link.  
7) Location + hours + map preview + CTA.  
8) Footer with contact info and social.

Services list:
- Watch Repair & Battery Replacement  
- Ring Sizing & Repair  
- Stone Replacement & Settings  
- Jewelry Cleaning & Polishing  
- Necklace & Bracelet Repair  
- Pearl Restringing  
- Jewelry Appraisals  
- Custom Design  
- Engraving  
- Restorations & Heirloom Repair

Booking/Quote sections (Home + dedicated pages):
- “Free 15‑min assessment” callout with 15‑min buffer mention.  
- Booking should reflect hours: Mon–Fri 10–6, Sat 10–4, closed Sun.  
- Include form components (name, phone, email, service, notes, preferred time).

Visual notes:
- Use luxury jewelry imagery, subtle gradients, gold accents.  
- Buttons: rounded, premium feel; primary burgundy, secondary gold outline.  
- Add subtle motion cues for CTAs and cards.

Output: full multi‑page UI screens (Home, Services, About, FAQ, Contact, Blog, Quote, Book a Repair).
