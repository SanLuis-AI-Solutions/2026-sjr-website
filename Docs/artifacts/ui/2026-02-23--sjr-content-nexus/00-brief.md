# UI Brief: SJR Content Nexus

## 1. Objective
Design a premium, automated command center for SJR (Susie's Jewelry Repair) to manage blog distribution, social media synchronization (GBP, Meta, Pinterest, LinkedIn), and the customer review loop.

## 2. Core Features
- **Global Status**: Real-time health of API integrations.
- **Content Pipeline**: Visual tracker for new blog posts and their auto-sync status across platforms.
- **Review Loop Monitor**: Tracking "Job Completed -> SMS Sent -> Review Received" flow.
- **Manual Overrides**: Quick-sync buttons for individual posts or platforms.
- **API Vault**: Secure section to manage long-lived tokens and refresh intervals.

## 3. Brand Identity
- **Primary**: Brand Burgundy (`#4A0E0E`)
- **Accent**: Brand Gold (`#D4AF37`)
- **Background**: Deep Burgundy / Black / Charcoal (Modern Luxury)
- **Vibe**: Modern Luxury meets "Mission Control." High-tech but grounded in master craftsmanship.

## 4. User Personas
- **Owner (Susie)**: Needs high-level "Are we active?" and "Are we getting reviews?" snapshots.
- **The Team**: Needs to see which jobs are in the review funnel.

## 5. Success Metrics
- **Clarity**: Zero confusion on whether an automation is active.
- **Trust**: Visual confirmation of "Successful sync" or "Error - click to fix."
- **Efficiency**: One-click manual triggers.
