# SEO AEO GEO Scorecard - 2026-07-09

## Current Scores

- SEO: 95/100
- AEO: 79/100
- GEO: 73/100

## Why These Scores

- SEO 95/100 is based on the latest SEOmator audit of the current site build. Strong metadata, crawlability, schema coverage, accessibility, and image markup are in place. Remaining gaps are mostly performance and production-header polish.
- AEO 79/100 is an operational score based on current answer-engine readiness: ChatGPT 80, Perplexity 70, Google AI 86, plus live `llms.txt`, FAQ/schema coverage, and the new AI discovery endpoints. It is ahead of GEO because the site is already understandable and citable, but still incomplete on discovery/freshness/entity authority.
- GEO 73/100 is the live public GEO Optimizer score after the schema/entity and AI discovery passes.

## Current Gaps

### SEO
- Mobile performance still has measurable room to improve.
- Production security/performance headers are not fully optimized.
- Some copy on key pages is repetitive enough to trigger light stuffing heuristics.

### AEO
- Instruction readiness is only 60.
- AI discovery is partial, not complete.
- Freshness signals are weak: no RSS feed and no dateModified-style reinforcement.

### GEO
- Brand/entity authority is still light.
- No Knowledge Graph pillar links beyond current local/social profiles.
- Perplexity-facing signals are weaker than ChatGPT and Google AI.

## Plan Toward 100

### SEO Plan
1. Run fresh production mobile PageSpeed and fix only measured issues.
2. Add/adjust production headers where safe: CSP, frame protection, compression-related checks if the platform allows it.
3. Reduce repetitive keyword density on homepage and key service pages without weakening local intent.
4. Keep image dimensions, priorities, and responsive behavior clean as new sections are added.

### AEO Plan
1. Add RSS feed and link it in the head for freshness and discovery.
2. Add stronger form labeling and extraction-friendly cues on booking/contact/quote flows.
3. Add dateModified-style freshness signals on blog and important evergreen pages.
4. Continue shaping copy into clearer factual blocks, lists, and concise answer sections.

### GEO Plan
1. Expand real entity authority only with verifiable profiles and references.
2. Improve the homepage and top service pages for citability: less repetition, more specific facts, stronger source diversity where appropriate.
3. Add the remaining lightweight discovery polish only if it is real and useful, not decorative.
4. Track public GEO monthly so we catch regressions after design/content changes.

## Highest-Leverage Order

1. Production mobile PageSpeed pass.
2. RSS plus freshness signals.
3. Copy cleanup on homepage and highest-traffic service pages.
