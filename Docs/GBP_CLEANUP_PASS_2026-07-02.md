# Google Business Profile Cleanup Pass

Updated: 2026-07-02

## Goal

Make the Google Business Profile reinforce the same booking-first message as the website:

`local repair need -> trust the in-house shop -> book a repair`

## Public Signals Checked

- Website contact page confirms address, phone, hours, and repair positioning.
- Homepage confirms the current booking-first CTA and priority services.
- Public third-party listings show the same core address and phone, but some older listings use older naming/category framing.

## Recommended GBP Fields

### Business Name

Keep:

`Susie's Jewelry and Watch Repair`

Reason: This matches local entity language seen in public listings and clearly includes watch repair.

### Primary Category

Recommended:

`Jewelry repair service`

If not available, use the closest available Google category:

`Jeweler`

### Secondary Categories

Use only if GBP allows them and they fit the real services:

- Watch repair service
- Jewelry designer
- Jewelry store

Avoid adding categories for services the shop does not actively want calls for.

### Website Link

Set to:

`https://www.susiesjewelryrepair.com/`

### Appointment / Booking Link

Set to:

`https://www.susiesjewelryrepair.com/book`

This is the highest-priority GBP field because the site is now booking-first.

### Business Description Draft

Use this if the current GBP description is weak or quote-focused:

> Susie's Jewelry and Watch Repair provides in-house jewelry and watch repair in Pasadena, TX. We help with watch batteries and repair, ring sizing, stone replacement, chain and bracelet repair, pearl restringing, cleaning, polishing, custom design, and heirloom restoration. Most services are handled Same Day or Next Day when possible, with clear communication before work begins. Book a repair time online or visit our Pasadena shop.

### Services To Confirm/Add

Priority services:

- Watch repair and battery replacement
- Ring sizing and repair
- Stone replacement and settings
- Necklace repair
- Bracelet repair
- Jewelry cleaning and polishing
- Pearl restringing
- Custom jewelry design
- Heirloom jewelry restoration

Each service should have a short description and link back to the relevant service page when GBP allows a URL.

### Photos

Add or refresh:

- Exterior/storefront
- Counter or intake area
- In-house workbench
- Watch battery/watch repair
- Ring sizing or ring repair
- Chain/bracelet repair
- Before/after repair examples if customer-safe
- Logo image

Avoid dark, blurry, or overly cropped images. Use real shop/service photos over generic jewelry stock.

### Product/Service Highlights

Use these short phrases consistently:

- In-house repairs
- Same Day/Next Day service when applicable
- Pasadena, TX
- Watch repair
- Ring sizing
- Chain and bracelet repair
- Stone replacement
- Book a repair

## Do Not Change

- Do not change hours unless the store confirms them.
- Do not move the profile to quote-first language.
- Do not add categories or services that invite irrelevant traffic.

## Approval Boundary

Prepared for GBP cleanup. Do not apply changes inside Google Business Profile without owner approval inside the GBP interface.
