## Editorial Checklist

For every post:

- confirm it is net-new against the current blog inventory
- confirm the first 100 words include the commercial or local angle
- add at least three internal links to service or conversion pages
- include an FAQ block only if it adds real new intent coverage
- include `Get Fast Quote` and `Book Repair` paths where appropriate
- verify `npm run build`
- run targeted blog-detail smoke coverage
