# Backlink Strategy

## Workflow
1. Audit current link profile
2. Identify target domains and assets
3. Plan outreach and partnerships
4. Track placements and quality
5. Monitor for toxic links

## Outputs
- Target list
- Outreach plan
- Tracking sheet
