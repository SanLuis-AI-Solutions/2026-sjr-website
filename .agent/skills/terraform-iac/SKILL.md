# Terraform IaC

## Workflow
1. Define environments and state strategy
2. Map resources to modules
3. Implement variables and secrets handling
4. Validate plan/apply in CI
5. Document rollback and drift checks

## Outputs
- Module map
- Variable list
- CI plan/apply checklist
- Drift/rollback notes
