# Accessibility Auditor

## Workflow
1. Run automated scans (WCAG/ARIA)
2. Review color contrast and focus order
3. Verify keyboard navigation
4. Check semantic structure and labels
5. Document fixes and re-test

## Outputs
- Audit report
- Fix list (priority)
- Re-test checklist
