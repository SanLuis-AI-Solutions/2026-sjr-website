# Competitor Analysis

## Workflow
1. Identify direct and indirect competitors
2. Compare positioning, offers, and funnels
3. Audit content and keyword coverage
4. Review backlink profiles
5. Summarize gaps and opportunities

## Outputs
- Competitor matrix
- Gap analysis
- Opportunity list
