# Data Pipelines

## Workflow
1. Define sources, destinations, and SLAs
2. Choose ETL/ELT pattern and scheduling
3. Design schemas and transformations
4. Add monitoring and retries
5. Validate data quality and lineage

## Outputs
- Pipeline architecture
- Source-to-target mapping
- Scheduling + retry plan
- Data quality checks
