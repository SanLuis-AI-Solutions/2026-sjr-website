# Compliance & Governance

## Workflow
1. Identify applicable regulations and data types
2. Map data flows and storage locations
3. Define retention and deletion policies
4. Verify consent, cookie, and privacy notices
5. Audit OSS licenses and third-party tools

## Outputs
- Compliance requirements matrix
- Data flow map
- Retention policy checklist
- OSS license audit notes
