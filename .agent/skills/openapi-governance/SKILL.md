# OpenAPI Governance

## Workflow
1. Define API domains and ownership
2. Draft OpenAPI specs with examples
3. Validate schemas and breaking changes
4. Generate clients/servers as needed
5. Enforce versioning and review gates

## Outputs
- OpenAPI spec checklist
- Versioning policy
- Breaking change rules
- Client generation notes
