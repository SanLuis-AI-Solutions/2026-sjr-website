# Observability Stack

## Workflow
1. Define SLOs/SLIs for critical journeys
2. Instrument logs, metrics, and traces
3. Set alerting thresholds and on-call playbooks
4. Create dashboards for service health
5. Run incident reviews and feed improvements

## Outputs
- SLO/SLI table
- Alerting rules
- Dashboard checklist
- Incident response playbook
